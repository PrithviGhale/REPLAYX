# REPLAYX 0.4.0

## What's New

**Windows signing.** This installer is distributed without Windows Authenticode signing. SmartScreen may show a warning. Download from this GitHub release and verify the SHA-256 below. If Windows blocks setup, keep protections enabled and wait for a Windows-signed build. In-app updates use REPLAYX?s existing Tauri signature.

### Crosshair Studio

- Choose a preset or customize the shape, color, size and position.
- Toggle it with a shortcut. Changes save when you leave the page.
- Use windowed or borderless mode where the game permits overlays. REPLAYX only shows the overlay when Windows confirms that it can exclude it from capture.

## Improvements and Fixes

### Recording and Instant Replay

- Corrected uneven FFmpeg audio packet timing. The playback mix and separate audio tracks keep their sample timing across replay segments. The fix passed a short Windows system-audio recording and Instant Replay check on Intel Quick Sync.
- Improved recovery when stopping a recording fails. Completed footage stays available under **Instant Replay → Recover**.
- FFmpeg remains the default. Experimental Native V2 uses supported hardware for compatible 1080p60 H.264 capture and shows a message when startup falls back.

### Windows setup

- Upgrades remove retired REPLAYX diagnostic tools from the program folder. Ordinary uninstall keeps your saved recordings and settings.

## Performance and compatibility

Native V2 used less video-encoder activity in the measured RTX 4070 external-display setup. The paired FPS estimate remained uncertain, and the motion run exceeded the baseline drift limit. Results depend on the GPU, display, game and settings.

REPLAYX targets 64-bit Windows 10 and 11 with Microsoft Edge WebView2 Runtime. Native V2 has Intel and NVIDIA validation on selected configurations. NVIDIA Native can fail to start on an Intel-driven hybrid display. Use FFmpeg on that configuration. Native Radeon and multi-display qualification remain open.

## Updating

Setup is per user. Use the Windows installer to upgrade an older copy. Select **Settings ? Updates ? Check Now** on versions with in-app updates. An Alpha.9 installation can discover the stable 0.4.0 release when its signed update manifest is published.
