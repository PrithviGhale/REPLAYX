# REPLAYX Alpha.9

A quicker start, a clearer interface and more control over your clips.
This update includes the work from the unpublished Alpha.7 and Alpha.8 builds.

## What's New

### Recording and Instant Replay

- **Quicker first start.** REPLAYX prepares its recording tools in the background after opening. On the test laptop, Windows Graphics Capture with Intel Quick Sync and system sound started in about 1.2 seconds, compared with about 3.3 seconds before. Other PCs and capture settings can differ.
- **Smaller Balanced clips.** Balanced 1080p60 now targets 15 Mb/s. Re-encoding one 60-second Fortnite clip averaged 15.2–15.8 Mb/s, equivalent to roughly 223–233 MB for two minutes with audio. This is an estimate from that test. Actual clip sizes and picture quality depend on the scene and settings.
- **A replay-length slider.** Choose from 30 seconds to 10 minutes in 15-second steps, plus 15 and 30 minutes. See an estimate of the saved clip's size before you record.
- **Experimental Windows Graphics Capture improvements.** GPU resizing and adjusted capture timing are available in Video settings. Desktop Duplication remains the default.

### Interface and game notices

- **A collapsible sidebar.** Fold the menu into a compact row of icons. REPLAYX remembers your choice.
- **Clearer messages.** Status messages use simpler words and have a close button. A message that happens again later can appear again.
- **Helpful error buttons.** Open the relevant setting or retry the action that failed. Technical details are available when needed.
- **Fewer repeated game notices.** Switching away from a game and back keeps the same session. Closing and relaunching the game starts a new one.
- **Refreshed pop-ups.** Recording and replay notices have clearer titles and game icons.
- **A lighter tray footprint.** One development-laptop test measured about 180 MB of memory, compared with about 370 MB before. Results vary by PC and workload.

### Audio and updates

- **A microphone switch on Home.** Mute or unmute your microphone during capture. The tray, shortcut and Audio page use the same state.
- **More time for changing audio devices.** REPLAYX retries for up to 10 seconds while a device is becoming available.
- **Signed in-app updates.** Settings → Updates can check for future compatible releases and verify their update signature. Notify me is the default mode. Windows code signing is separate and remains unavailable.

## Improvements and Fixes

- Choosing a two-minute replay no longer reports an invalid duration.
- Existing 15- and 30-minute replay settings stay unchanged and display correctly.
- Closing an old message cannot close a newer message.
- Damaged settings are backed up where possible. If REPLAYX cannot safely write settings, it explains the problem and keeps them read-only until restart.
- A microphone that stops sending sound is no longer automatically described as permission-blocked.
- Performance cards and the empty Clips library are clearer.
- Replay-buffer maintenance does less repeated work.
- Documentation and developer tools are grouped into easier-to-find folders.

## Download and Update

Download **[REPLAYX.exe](https://github.com/PrithviGhale/REPLAYX/releases/download/v0.3.1-alpha.9/REPLAYX.exe)** to install the app.
Requires 64-bit Windows 10 or Windows 11. Hardware video encoding is recommended.

Alpha.6 and earlier need a manual installer update to reach this version.
The installer is designed to preserve settings, clips and playtime. Isolated
clean-install, Alpha.4/Alpha.8 upgrade and uninstall-retention tests for this
candidate remain unfinished.

The installer has an update signature and the SHA-256 checksum shown on the release page.
It is not Windows code-signed. If Windows Security or SmartScreen blocks it,
stop and review the warning. Keep Windows security protections enabled.
The FFmpeg source archive is supplied for licensing compliance. It is not
needed to run REPLAYX.

## Known Limitations

- **This is an alpha prerelease.** Final installed-app validation and real installer-based updating remain unfinished.
- Recording can reduce game FPS on hybrid laptops. A Fortnite test using Windows Graphics Capture and Quick Sync measured about 19% overhead. This release does not establish ShadowPlay-level overhead.
- Physical Bluetooth headset switching, microphone listening quality, editor multitrack playback, fullscreen stretched-resolution transitions, multi-monitor notices and strong anti-cheat compatibility still need additional hardware testing.
- The two-minute clip-size figure above is extrapolated from a re-encode. A fresh two-minute gameplay replay with the final build has not been measured.
- Windows Graphics Capture remains experimental. Some exclusive-fullscreen games can hide the on-screen notices.

Automated source checks pass. They do not replace the outstanding hardware and
installation tests. See the repository's validation report and known limitations
for the recorded evidence.
