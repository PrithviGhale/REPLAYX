**REPLAYX** is a free, open-source game recorder for Windows: Instant Replay, smooth hardware-accelerated recording, clips sorted by game, a Voice Enhancer for your microphone and local playtime tracking. No account, no ads, nothing uploaded.

This alpha makes *Start with Windows* dependable and comes with a new project page and documentation. Recording works exactly as in 0.3.1-alpha.4.

## What's New

- **A new home on GitHub:** a short project page with a direct download, and step-by-step guides for [getting started](https://github.com/PrithviGhale/REPLAYX/blob/main/docs/GETTING_STARTED.md), [features](https://github.com/PrithviGhale/REPLAYX/blob/main/docs/FEATURES.md), the [FAQ](https://github.com/PrithviGhale/REPLAYX/blob/main/docs/FAQ.md) and [troubleshooting](https://github.com/PrithviGhale/REPLAYX/blob/main/docs/TROUBLESHOOTING.md).

## Improvements and Fixes

- **Start with Windows** now follows the setting exactly: REPLAYX opens quietly in the tray when you sign in, and turning the setting off removes the startup entry right away.
- Fixed a blank Windows Terminal window that could open at sign-in on PCs that had run a development build of REPLAYX.
- Every release is now built from a clean checkout by GitHub Actions, with the FFmpeg source package attached automatically.

| `SHA256SUMS.txt` | Checksums to verify your download |

## Installation

1. Download `REPLAYX_0.3.1-alpha.5_x64-setup.exe`.
2. *(Recommended)* Check it in PowerShell with `Get-FileHash .\REPLAYX_0.3.1-alpha.5_x64-setup.exe` and compare with `SHA256SUMS.txt`.
3. Run the installer (per-user, no administrator rights). Builds aren't code-signed yet, so SmartScreen may appear: choose **More info → Run anyway** if the checksum matched.

Updating from 0.3.1-alpha.4: just run the new installer. Your clips, settings and playtime are kept.

Requires Windows 10 or 11 (64-bit). A GPU with hardware video encoding (NVIDIA, Intel or AMD) is recommended.

## Known Limitations

- Alpha software: tested mostly on one laptop (Intel Iris Xe + NVIDIA RTX 4070 Laptop).
- Not code-signed yet, and in-app updates are not enabled yet.
- The status overlay can't appear over exclusive full-screen games (a Windows rule); use borderless or windowed mode.
- The Voice Enhancer was measured with synthetic speech; real-world feedback is welcome.
