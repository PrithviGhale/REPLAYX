# REPLAYX 0.4.0-rc.3

This local Windows release candidate focuses on dependable recordings, Instant Replay and Crosshair Studio.

## Recording and replay

- Fixed uneven FFmpeg audio timestamps in recordings and replays. The mix and separate audio tracks now keep their sample timing.
- Completed footage stays available through **Instant Replay → Recover** if stopping a recording fails. REPLAYX clears the stalled saving state so you can use recovery immediately.
- FFmpeg remains the default. Native V2 stays experimental in Video settings and reports when it falls back.

## Crosshair Studio

- Resize, recolor and position the click-through overlay, choose a preset, and toggle visibility with your shortcut.
- Your last edit saves when you leave Crosshair Studio. Windows capture exclusion is required for the overlay to show.

## Windows setup

This candidate keeps the per-user installer and product identity used by earlier versions. The sidebar and About page show the version of the current build. The local setup is for isolated qualification. Clean installation, upgrades, uninstall data retention and a signed updater install still need verification on the final candidate.

See [known limitations](../guide/KNOWN_LIMITATIONS.md) and [installer qualification](../engineering/INSTALLER_QUALIFICATION.md).
